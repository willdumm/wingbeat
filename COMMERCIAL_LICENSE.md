## The AGPL already permits commercial use — so why a commercial license?

The AGPL does not forbid charging money, running a business on this
software, or using it inside a company. What it requires is **network
copyleft**: if you run a modified version of this software as a network
service, anyone who interacts with that service over the network must be
able to obtain the corresponding source code of the version you're running,
including your modifications (AGPL-3.0 §13).

For most companies — and especially for anyone running **managed hosting**
(operating this software as a paid service on behalf of other customers) —
that obligation is impractical: it would require publishing the source of
your entire operator layer (deployment tooling, customer management,
proprietary extensions, etc.) to every user of the service.

A commercial license removes that requirement. It lets you:

- Run modified or unmodified versions of the software, including as a
  managed/hosted service for third parties, without publishing your
  modifications or operator-layer source.
- Distribute the software as part of a closed-source commercial product.
- Self-host commercially without complying with AGPL's source-disclosure
  terms.

If none of the above applies to you — for example, you're self-hosting for
personal, internal, non-commercial, or already AGPL-compliant use — you do
not need a commercial license. See the "Do I need a commercial license?"
section in [`README.md`](README.md#license) for concrete examples.
