# Settings

Opened from the gear icon on the dashboard or analytics page. Split into two
groups:

- **[User settings](user-settings)** — available to every signed-in user
  (Viewer or Admin), and scoped to that user or device.
- **[Admin settings](admin-settings)** — only visible to users with the Admin
  role. Viewers don't see these sections at all.

See [Users & Devices](../features/users-and-devices) for how roles and
invites work.
